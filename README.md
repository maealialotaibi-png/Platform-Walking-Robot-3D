# Platform Walking Robot – 3D Design

## Design Link

https://owlcad.com/app?shared=800ba4ee-0c0d-41fb-8827-87a0c449337c

## Project Description

This project is a 3D parametric CAD model of the Platform Walking Robot developed based on the robot design from the previous task.

The model represents the robot body, four legs, and cylindrical joints added to the legs to represent the mechanical movement points of the walking robot.

## Design Software

The design was initially intended to be created using Onshape. However, technical and performance issues were encountered while using Onshape, which affected the modeling process.

Therefore, OwlCAD, a browser-based parametric CAD tool, was used to complete the 3D model.

## Main Components

- Robot body
- Four legs
- Cylindrical joints
- Mechanical structure for the walking platform

## STL File

The final 3D model has been exported as an STL file and uploaded to this repository.

File: `Platform-Walking-Robot.stl`

## Design Features

- 3D parametric CAD modeling
- Four-legged walking robot structure
- Cylindrical joints on the legs
- Design based on the original Platform Walking Robot concept
